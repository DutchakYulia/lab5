# Лабораторна робота 5

## Тема

Написання тестів для графічного інтерфейсу.

## Ресурс для тестування

Обрано реальний навчальний вебресурс: https://www.saucedemo.com/

Цей сайт призначений для тренування UI/e2e-тестування: має сторінку логіну, список товарів, сортування, кошик і сторінки товарів. Тому можна візуально відкрити сайт у браузері й порівняти дії тестів із реальною поведінкою інтерфейсу.

## Короткі тест-кейси

1. Перевірити, що сторінка логіну має очікуваний заголовок `Swag Labs`.
2. Перевірити, що поля логіну, пароля та кнопка входу відображаються.
3. Перевірити, що стандартний користувач може авторизуватися та бачить 6 товарів.
4. Перевірити, що товар можна додати в кошик.
5. Перевірити, що сортування товарів за ціною від меншої до більшої працює коректно.
6. Перевірити, що сторінка деталей товару відкривається зі списку товарів.

## Дані для входу

```text
Username: standard_user
Password: secret_sauce
```

## Запуск

Запуск у звичайному headless-режимі:

```bash
npm test
```

Запуск із видимим браузером, щоб побачити UI під час виконання:

```bash
npx playwright test --headed
```

Щоб покроково подивитися виконання:

```bash
npx playwright test --debug
```
